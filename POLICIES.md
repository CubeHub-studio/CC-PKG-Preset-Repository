# Project Policies

## 1. License

This repository is distributed under the **Lunar Cubes License 1.1**.

Installation is granted. Modification and creation of derivative versions are granted.

If a modified version is published, it must retain clear and reasonably visible credits for everyone known or documented to have helped create, develop, improve, test, or maintain the software, and it must credit **Cubes Studio** for creating the original version.

See [LICENSE](LICENSE) for the complete license terms.

## 2. Attribution

Cubes Studio attribution must not be removed or falsely represented. A modified version may have its own name and branding, but it must not falsely claim to be the original Cubes Studio version.

## 3. Contributions

Contributions should be useful, understandable, tested when practical, and compatible with the project's goals. Contributors are responsible for ensuring that their submitted work can legally be contributed under the project's license.

## 4. Packages

Packages should have a clear purpose and avoid unnecessary duplication. Package metadata must accurately describe the package and its supported devices.

## 5. Security

Do not intentionally submit malware, destructive code, credential theft, unauthorized access mechanisms, or other intentionally harmful functionality. Security vulnerabilities should be reported privately according to [SECURITY.md](SECURITY.md).

## 6. Community

All participants must follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Maintainers may moderate project spaces to keep them useful, safe, and constructive.

## 7. Third-party content

Third-party code, assets, documentation, or dependencies must retain any attribution and license requirements that apply to them. Do not add material that you do not have permission to redistribute.

## 8. Repository integrity

Do not intentionally corrupt repository metadata, package indexes, manifests, checksums, release files, or other project infrastructure. Changes that break package installation or repository integrity may be reverted.

## 9. Modification and redistribution

Modified versions may be distributed under the rights granted by the Lunar Cubes License 1.1, provided that its credit and attribution requirements are preserved.

## 10. Policy changes

Cubes Studio may update these project policies as the project evolves. License rights remain governed by the applicable license.
