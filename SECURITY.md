# Security Policy

## Reporting a vulnerability

Please do not publicly disclose an unpatched security vulnerability through a GitHub issue, discussion, pull request, or other public project channel.

Report security issues privately to the project maintainers through the contact method provided by the repository.

A useful report should include the affected package or version, reproduction steps, potential impact, and relevant proof of concept information where safe.

Do not include passwords, API keys, access tokens, or unrelated private information.

## Disclosure

Maintainers may investigate, reproduce, fix, and coordinate disclosure of confirmed vulnerabilities. Public disclosure should preferably occur after a fix or mitigation is available.

## Safe testing

Only test systems you own or have explicit permission to test. Do not intentionally attack other users, servers, computers, repositories, or services while testing this project.

## Scope

This policy covers security issues in the CC-PKG Preset Repository and software distributed from it. Issues caused entirely by third-party software should also be reported to the appropriate project or service.
