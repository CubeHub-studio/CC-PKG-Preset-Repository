# Code of Conduct

## Our commitment

Cubes Studio is committed to maintaining a welcoming, respectful, and constructive community around this project.

Everyone participating in this project is expected to contribute in a way that supports collaboration, learning, creativity, and technical discussion.

## Expected behavior

Participants are expected to:

- Treat other people with respect and basic courtesy.
- Give constructive feedback focused on the project, code, documentation, or ideas.
- Credit other people's work when using or building upon it.
- Respect different levels of experience and perspectives.
- Keep discussions relevant and productive.
- Follow GitHub's Terms of Service and applicable policies.
- Report security issues and serious problems responsibly rather than intentionally exploiting them against other contributors.

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, threats, intimidation, or targeted abuse.
- Discrimination or hateful conduct directed at other participants.
- Personal attacks, insults, or deliberate humiliation.
- Doxxing or publishing another person's private information without permission.
- Spam, malicious content, or deliberate disruption of the project.
- Impersonating Cubes Studio, project maintainers, or contributors.
- Removing or falsifying required attribution or credits.
- Knowingly submitting malicious code, malware, or intentionally harmful changes.
- Using project discussions, issues, pull requests, or other project spaces to facilitate illegal activity.

## Project moderation

Project maintainers may remove content, close discussions, reject contributions, restrict participation, or take other reasonable moderation actions when behavior violates this Code of Conduct or materially disrupts the project.

Moderation decisions may consider the context, severity, frequency, and impact of the behavior.

## Reporting

If you encounter conduct that violates this Code of Conduct, report it privately to the project maintainers through the contact method provided by the repository.

For security vulnerabilities, use the project's security reporting process rather than publicly posting exploit details.

## Scope

This Code of Conduct applies to project spaces and activities associated with this repository, including issues, pull requests, discussions, documentation, and other community spaces operated for the project.

## Enforcement

Maintainers will make reasonable efforts to review reports and respond appropriately. Reports will be handled as privately as reasonably possible.

This Code of Conduct is intended to establish community standards. It does not replace GitHub's Terms of Service, GitHub policies, or applicable law.
