# Support

## Getting help

For questions, package problems, installation problems, or feature requests, use the repository's GitHub Issues or Discussions where appropriate.

Before asking for help, check the package help output, README, and existing issues or discussions.

## Bug reports

Include the package name and version, CC:Tweaked/Minecraft version, reproduction steps, and the exact error message when possible.

Do not post private credentials, passwords, API keys, or other sensitive information.

## Security issues

Do not publicly post details of an unpatched security vulnerability. Follow [SECURITY.md](SECURITY.md).
